# 🐍 파이썬 코딩테스트 스터디

매주 알고리즘 주제를 정해서 문제를 풀고, 각자 폴더에 풀이를 올리는 스터디

**2026-08-17부터 진짜진짜 시작**

## 📌 운영 방식

- 일주일에 **5문제 이상** 풀기
- 문제를 풀면 본인 폴더에 파일 업로드
- 파일 규칙: `week주차/이름/문제.py`
  - 예) `week01/홍길동/백준_1234_두수의합.py`

## 📂 폴더 구조

```
coding-test-study/
├── week01/
│   ├── 총/
│   └── 우린/
├── week02/
│   ├── 총/
│   └── 민엽/
...
```
